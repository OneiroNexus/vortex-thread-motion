# Preserved Vortex Threads coordinate recipe

This directory preserves the recovered original recipe, decoder, renderer sources and historical result record byte for byte. `HISTORICAL-README.md` documents the original Linux experiment; its measured sizes and times are historical evidence rather than results of the current machine.

Run the portable checker from the repository root with Python 3.12 and NumPy 2.3.5:

```sh
python -m pip install numpy==2.3.5
python legacy/recipe/verify_recipe.py --output results/my-legacy-replay
```

The output directory must be new. `replay.json` records native source/reference/decoder checks and a **separate** `historical_digest_matched` boolean. Exit 0 means native checks pass. That boolean may be false on a different platform while the native decoder agrees byte for byte with the native reference. Exit 1 denotes a native verification failure; exit 2 denotes CLI/output-directory failure. No remote CI pass is implied by the supplied workflow.

The canonical target has 117,676,800 bytes of pre-camera binary64 XYZ coordinates, not pixels or a video container. The historical expected SHA-256 is `d1aa661c76182cd6784a53b127185db4e2d55e7011b1a4564fa53571e401bfa8`, tested originally on Linux x86-64 with Python 3.12.14 and NumPy 2.3.5. Floating-point identity across CPUs, NumPy builds and math libraries is not promised. A mismatching historical checksum must be reported, not silently treated as recovered historical bytes.

The checker verifies preserved source hashes, extracts the original renderer's coordinate definitions, builds the original two-panel reference, and launches the unchanged decoder in a fresh process. It compares the complete native streams, verifies a gzip round trip, records gzip size, and checks changed-seed and one-bit-edit controls. It also records the recipe-plus-decoder ZIP size. It does not benchmark video compression, new physical data or a flow predictor.

The original renderer files include Linux fonts, PIL and ffmpeg rendering. The portable checker avoids those dependencies by excluding only PIL/font initialization from the pre-render prelude and never executing the rendering loop. Coordinate math is preserved. Original renderer files are supplied for provenance; do not run them to perform this check. Required dependencies are NumPy and the Python standard library, with about 313 MB of temporary disk space. Temporary coordinate streams are removed; only the JSON report remains.

The 177-byte recipe assumes a compatible shared decoder. The two-entry ZIP includes recipe and decoder source; runtime dependencies are excluded. A self-authored target is deliberately generated by its recipe, so exact replay does not establish a compression advantage on independently observed motion or physical formation of the scripted opening.
